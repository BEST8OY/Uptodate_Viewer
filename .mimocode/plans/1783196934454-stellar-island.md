# Add Recent Searches to SearchScreen

Show recent search queries when SearchScreen opens with an empty query. Gives users quick access to previous searches.

## 1. SearchViewModel — add recent searches

**File**: `SearchViewModel.kt`

Add a `recentSearches` state persisted via `SavedStateHandle`:

```kotlin
companion object {
    private const val KEY_QUERY = "search_query"
    private const val KEY_AUDIENCE = "selected_audience"
    private const val KEY_RECENT_SEARCHES = "recent_searches"
    private const val MAX_RECENT_SEARCHES = 10
}

private val _recentSearches = MutableStateFlow(
    savedStateHandle.get<List<String>>(KEY_RECENT_SEARCHES) ?: emptyList()
)
val recentSearches: StateFlow<List<String>> = _recentSearches
```

In `search()`, after successful search, add query to recent searches (deduped, max 10):

```kotlin
// After successful search:
val current = _recentSearches.value.toMutableList()
current.remove(query)
current.add(0, query)
if (current.size > MAX_RECENT_SEARCHES) current.removeLast()
_recentSearches.value = current
savedStateHandle[KEY_RECENT_SEARCHES] = current
```

Add a clear function:

```kotlin
fun clearRecentSearches() {
    _recentSearches.value = emptyList()
    savedStateHandle[KEY_RECENT_SEARCHES] = emptyList<String>()
}

fun removeRecentSearch(query: String) {
    val current = _recentSearches.value.toMutableList()
    current.remove(query)
    _recentSearches.value = current
    savedStateHandle[KEY_RECENT_SEARCHES] = current
}
```

## 2. SearchScreen — display recent searches

**File**: `SearchScreen.kt`

When query is empty and no search has been performed, show recent searches list:

```kotlin
// In the LazyColumn, when suggestions.isEmpty() && !hasSearched:
if (recentSearches.isNotEmpty()) {
    item {
        Row(
            modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp, vertical = 8.dp),
            horizontalArrangement = Arrangement.SpaceBetween,
            verticalAlignment = Alignment.CenterVertically
        ) {
            Text("Recent searches", style = MaterialTheme.typography.labelLarge)
            TextButton(onClick = { viewModel.clearRecentSearches() }) {
                Text("Clear all")
            }
        }
    }
    items(recentSearches) { query ->
        ListItem(
            headlineContent = { Text(query) },
            leadingContent = { Icon(Icons.Default.History, ...) },
            trailingIcon = {
                IconButton(onClick = { viewModel.removeRecentSearch(query) }) {
                    Icon(Icons.Default.Close, ...)
                }
            },
            modifier = Modifier.clickable {
                textFieldState.clearText()
                textFieldState.edit { append(query) }
                viewModel.search(query)
                hasSearched = true
            }
        )
    }
}
```

## Verification

1. Open SearchScreen with empty query → recent searches shown (or empty state)
2. Perform a search → query added to top of recent searches
3. Repeat search → no duplicates, moved to top
4. More than 10 searches → oldest dropped
5. Tap recent search → re-runs search
6. Tap X on recent search → removes it
7. Tap "Clear all" → clears all recent searches
8. Process death → recent searches restored from SavedStateHandle
