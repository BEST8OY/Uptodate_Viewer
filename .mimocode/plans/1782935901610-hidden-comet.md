## Implemented Changes

### Files Modified
- `app/src/main/java/com/clinref/app/ui/content/CssBuilder.kt` — full rewrite
- `app/src/main/java/com/clinref/app/ui/content/ContentViewModel.kt` — entry point updated
- `app/src/main/java/com/clinref/app/ui/content/GraphicSheet.kt` — entry point updated

### Architecture Fixes
1. **CSS Variables**: Added `:root` block with all 20 theme tokens as CSS custom properties. All CSS rules now reference `var(--xxx)` instead of baked-in Kotlin string interpolation. Theme/dark-mode switching now swaps variable values at one location.
2. **Deduplication**: Extracted `sharedTableStyles()` containing `.subtitle1`, `.subtitle2`, `.indent1/.indent2`, `.divider_bottom/.divider_top`, `.nowrap_whitespace`, `.extra_spacing_top`. Both `tables()` and `graphicViewer()` now reference this shared fragment.
3. **Entry Point Separation**: Renamed `build(vararg sections)` to `buildDocumentCss()` (assembles all 11 sections + responsive + print). Added `buildGraphicPopupCss()` for the standalone graphic popup WebView. No more generic assembler that trusts callers.
4. **`hexToRgba` hardened**: Now handles 3-char shorthand (`#fff`), validates input length, returns safe fallback on malformed data.
5. **Vestigial `dd::after` rules removed** — HtmlNormalizer already replaces `<dl>` with `<ul>`.
6. **Typography normalized**: Font-sizes reduced from ~20 to ~12 distinct values. Line-heights reduced from 8 to 4 values (1.3, 1.4, 1.5, 1.6).

### UX / Accessibility Fixes
7. **`.visuallyHidden` fixed**: Changed from `display: none` to the standard accessible-hidden pattern (`position: absolute; clip: rect(0,0,0,0); 1px size`). Elements are now hidden visually but remain in the accessibility tree.
8. **Responsive strategy added**: Two `@media` breakpoints (480px, 768px) with fluid padding, scaled typography, and tighter spacing on small screens. Container padding goes from 40px to 20px to 12px as viewport narrows.
9. **Print stylesheet added**: `@media print` with white background, hidden calculator buttons, expanded link URLs, grayscale-friendly severity boxes, `break-inside: avoid` for warning blocks.
10. **Collapsible affordance**: Added CSS `::after` chevron (▶) that rotates 90° when `.open` class is present. Uses `user-select: none` for better touch interaction.
11. **Severity differentiation**: `.block.coi .drugH1` now shows a "COI" pill label. `.block.war .drugH1` now shows a "WARNING" pill label. No longer relies on color alone.
12. **Calculator reset button**: Persistent danger styling (red text + border at rest, filled red on hover). Touch users now see the destructive signal before tapping.
13. **`input[readonly]`**: Added dashed border, secondary text color, and `cursor: default` to distinguish from editable inputs.
14. **H1 unified**: Single `h1` rule with `topic-title` override for size/margins only. No conflicting border treatments.
