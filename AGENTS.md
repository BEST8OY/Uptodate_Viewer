# UpToDate Viewer Android

## What this is

Android app that reads and displays UpToDate clinical resource content from locally stored offline database files (SQLite + Zstd-compressed blobs).

## Build & run

```bash
# Gradle wrapper not committed — generate first
gradle wrapper --gradle-version 9.5.1

./gradlew assembleDebug
./gradlew assembleRelease
./gradlew lint
./gradlew testDebugUnitTest
./gradlew check
```

## Architecture

- **Single module** (`:app`), single activity, all-Compose UI.
- **Clean Architecture**: `data/` (SQLite + Zstd repos), `domain/` (models + persistence), `ui/` (screens + ViewModels).
- **DI**: Dagger Hilt with KSP (not kapt).
- **Navigation**: **Navigation 3** (`1.1.1`, alpha) — imports from `androidx.navigation3.*`, not `navigation-compose`. Routes are `@Serializable` `NavKey`s (`sealed interface TopLevelRoute : NavKey`). `TopLevelBackStack` is a custom multi-tab backstack class.
- **No Room**. Direct `SQLiteDatabase.openDatabase(OPEN_READONLY)` on UpToDate's proprietary `.sqlite`/`.db` files.
- **Content rendering**: WebView with `@JavascriptInterface`, HTML processed by `HtmlProcessor`, CSS generated by `ContentCssBuilder`.
- **Persistence**: DataStore Preferences for database location URI + user preferences.
- **Theme**: `Material3Expressive` (`ExperimentalMaterial3ExpressiveApi`), dynamic color on Android 12+, medical safety colors.

## Required database files

The app expects all 6 files in a user-selected directory:

- `unidex.en.sqlite` (index)
- `utdasset.sqlite` (graphics/assets)
- `utdtoc.db` (table of contents)
- `fsearch.db`, `fcontentsearch.db` (search)
- `utdqf.sqlite` (quick facts)

## Quirks & gotchas

- **No Room** — don't add Room annotations. SQLite is opened read-only by `DatabaseManager`.
- **Navigation 3, not v2** — don't import `NavController`, `NavHost`, `composable()` from `navigation-compose`. Use `NavKey`-based routing with `@Serializable` data objects/classes.
- **KSP, not kapt** for Hilt.
- **Kotlin Serialization, not Gson/Moshi** — `@Serializable` data classes (`kotlinx.serialization`).
- **ProGuard keeps specific data model classes** (`app/proguard-rules.pro`). When adding new `@Serializable` data models used with the serialization plugin, check whether they need explicit keep rules.
- **Zstd decompression** — content blobs in DB are Zstd-compressed. `ZstdDecompressor` checks for Zstd magic bytes `0x28, 0xB5, 0x2F, 0xFD`.
- **WebView app actions** — HTML links with `javascript:appAction(...)` are rewritten to `appaction://` URIs by `HtmlProcessor`. Handled via `AppAction.SCHEME = "appaction"`.
- **No CI/CD**, no formatter config, no custom lint config, no test sources yet (dependencies declared only).
- **minSdk 32 (Android 12L)**, **targetSdk 37 (Android 15)**.
